# Arjunprabhulal Superpdf

## How do I install these formulae?

`brew install arjunprabhulal/superpdf/<formula>`

Or `brew tap arjunprabhulal/superpdf` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "arjunprabhulal/superpdf"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
